# ことのは かるた

小学生向けの、サーバー不要のかるた読み上げアプリです。

公開ページ：**[ことのは かるた](https://tanashou1.github.io/karuta-reader/)**

## GitHub Pagesで公開

1. GitHubのリポジトリにこのフォルダーの内容（`.github`を含む）を追加し、`main`ブランチへpushします。
2. リポジトリの Settings → Pages → Build and deployment → Source を **GitHub Actions** にします。
3. Actions の **Publish GitHub Pages** を実行します。以降はmainへのpushで更新されます。
4. 実行結果の `github-pages` のURLが公開先です。

配布用のエンジンを同梱しているので、そのまま動作します。ソースを変更して再ビルドする場合は `npm ci` → `npm run build` を実行します。ローカルでは `python3 -m http.server 8000` をこのフォルダーで実行し、 http://localhost:8000 を開いてください。

## 使い方

- 「かるたセット作成」でテキストを取り込むか、新しいセットを手入力します。
- 1行を1枚の読み札として扱い、空行は無視します。UTF-8とShift_JISの読み込みに対応します。出力はUTF-8です。
- 保存したセットは編集・削除できます。手入力の編集画面からテキストを書き出せます。
- 「はじめる」でセット・順番／ランダム・音声を選びます。
- 最初の札を自動で読み、その後は「次へ」で進みます。「戻る」で前の札を再読、「もう一度きく」で現在の札を再読できます。
- ランダムでも同じ札は重複せず、「戻る」はその回の出題順をたどります。

## 読み上げの設定

メニューの「設定」から、1枚を読む回数（1〜10回）と、繰り返すときの時間間隔（0〜60秒、0.1秒刻み）を変更できます。初期値は1回・2秒です。時間間隔は、読み終わってから同じ札を再び読むまでの待ち時間です。1回の場合は待ち時間を使いません。

設定は「設定を保存」でブラウザのlocalStorageに保存され、再読み込み後も引き継ぎます。ゆっくり音声・取り込んだ音声・ブラウザ音声のすべてに適用します。「次へ」「戻る」「終了」「もう一度きく」を押したときは、途中の繰り返しや待ち時間を中止します。次の札へは自動で進まず、「次へ」で進みます。

## 文章からゆっくり音声を生成

「はじめる」→ 音声の「ゆっくり音声（文章から自動作成）」を選んで開始すると、全札の音声をまとめて生成し、読み札と一緒にブラウザ内に保存します。次回は「保存したゆっくり音声」を選べば再生成せずに遊べます。

セット編集画面の「ゆっくり音声を作成・設定する」→「文章から音声をつくる」からも生成できます。こちらは生成後に「このセットを保存」を押してください。

- 漢字かな交じり文にも対応します。固有名詞などの読みが違う場合は、読み札をひらがなに直して生成しなおしてください。
- 初回は約23MBのエンジン・辞書を読み込みます。WebAssemblyとModule Workerに対応するモダンブラウザが必要です。
- 文章の読み変換・音声生成はWeb Workerで端末内で行います。文章を外部サービスへ送信しません。APIキーや音声サーバーは不要です。
- 作成の進捗を表示し、中止できます。失敗・中止した場合、以前保存した音声は残ります。長すぎる文章などで失敗した場合は、該当する札の番号を表示します。
- 全札の生成が終わってから再生します。ブラウザが初回の自動再生を止めた場合は、「もう一度きく」を押してください。
- 読み札を変更・並べ替えた場合は、音声も生成しなおしてください。

### 使用エンジンとライセンス

本アプリは株式会社アクエストの **AquesTalk旧版（F1）** を使用し、その著作権は同社に帰属します。`aquestalk.js@1.0.7` に含まれる旧版の使用許諾には、無償の使用と、条件を満たすDLLの組み込み配布が定められています。現行版のライセンス条件と混同しないでください。

配布物には音声パッケージ `speech/f1.zip` を変更せず保持し、その中の `f1/AqLicence.txt` と `f1/AquesTalk.dll` を一緒に保持しています。許諾書のコピーも `speech/licenses/AqLicence.txt` に収録しています。著作権と使用エンジンはアプリのフッターに表示しています。

使用ライブラリ：

- [aquestalk.js](https://github.com/y52en/aquestalk.js) 1.0.7：MIT。エンジン本体は上記の別ライセンスです。
- [kanji2koe-openjtalk](https://github.com/y52en/AqKanji2Koe-OpenJTalk-WASM) 0.1.0：漢字の読み変換（jpreprocess / NAIST-JDic）。
- v86、JSZip、encoding-japaneseなどの通知を `speech/licenses/` に同梱しています。

### 音声ファイルの取り込みも可能

セット編集画面で1行目は `1.wav`、2行目は `2.wav` のように番号を付けて取り込めます。MP3・OGG・M4Aにも対応します。音声はテキスト出力に含まれません。

ブラウザの日本語音声も引き続き選べますが、ゆっくり音声ではありません。

## 保存について

読み札と取り込んだ音声は、端末のブラウザ内のIndexedDBに保存します。サーバーへのアップロードや他端末への同期はありません。ブラウザのデータ削除・プライベートモード・容量制限などで失われることがあるため、テキストと元音声を保管してください。公開URLのドメインが変わると保存先も別になります。同じドメインのGitHub Pagesではブラウザの保存領域が共有されます。

Google Fontsから丸ゴシックのフォントを読み込みます。オフラインでは端末の標準フォントで表示されます。

## 検証

`npm test` で実エンジンの漢字・かな文章からのWAV生成と、配布用Workerによる生成を確認します。構文確認と実生成を検証済みです。実ブラウザでの再生・IndexedDB保存・スマートフォンでの操作は未検証です。公開後に対象端末で確認してください。
